# Scripts

Build and utility scripts for the Ryos website.

| File | Description |
|---|---|
| `local_on.bat` | Start the Vite dev server (`npm run dev` → localhost:3000) |
| `local_off.bat` | Kill all Node processes (stop the dev server) |
| `publish.bat` | Git add, commit (prompts for message), and push |
| `test.bat` | Run a production build (`npm run build`) |
| `create-404.cjs` | Generate `dist/404.html` for GitHub Pages SPA fallback |
